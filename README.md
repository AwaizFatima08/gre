# Prep Simulator for GRE

A free Android app by [HomiLabs](https://homilabs.org) for the GRE General Test: 20 full-length mock tests in the
current shorter format (Issue essay, two Verbal and two Quantitative sections, adaptive section 2), estimated scores
with every answer explained, lessons and practice for every topic, essay practice with model answers, vocabulary
flashcards, and tips and study plans. Independent practice material; GRE® is a registered trademark of ETS, which does
not endorse this app.

- App: Flutter, in `lib/`. Project notes: `CLAUDE.md`.
- Content: `content/`, built into `assets/data/` by `tool/build_content.py`.
- Website: `website/`, live at https://gre.homilabs.org.
- Release and hosting: `docs/release-and-hosting.md`.
